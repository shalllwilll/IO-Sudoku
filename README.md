# IO Signal Sudoku

VIT Code Apex 3.0, Emerson track, PS #02: allocate DeltaV IO signals from an MDB
workbook into cabinets, CIOCs, baseplates and CHARMs, and write the 76-column
allocation template.

## Branches

- `backend`: allocation engine, API and a plain React test UI.
- `frontend`: the 3D plant view and screens (separate teammate).
- `main`: integration only, at release.

Hackathon data files are for hackathon use only and are never committed
(`backend/data/` is git-ignored).
