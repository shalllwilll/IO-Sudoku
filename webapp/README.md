# IO Signal Sudoku: system UI

```bash
npm install
npm run dev -- --port 5180   # backend expected at http://localhost:8000 (VITE_API_BASE)
npm run build
```

Status: design lock. Login, Run, Layout and the 3D placeholder are implemented on synthetic data (`src/preview`).
